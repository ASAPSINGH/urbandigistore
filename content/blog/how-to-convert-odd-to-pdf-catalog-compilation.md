# How to Convert ODD to PDF: Catalog Compilation

Managing digital documents requires strict compliance with formatting and font subsets. Here is a direct definition of this standard.

**PDF (Portable Document Format)** is a digital document standard designed to preserve formatting across all devices. Modern PDF operations utilize local browser APIs to merge, split, or secure pages without server uploads, protecting document data.

If you are compiling a technical schema specification, archival standard sheet, or academic manuscript document containing multiple TEI ODD files, consolidating them into a single file is key. Converting **ODD to PDF** compiles these text schema files into standard formatted document pages.

## 📐 Formatting ODD manuscript inside PDF Pages

To ensure your compiled ODD text descriptions fit standard PDF grids:
*   **Scale Font Sizes**: Use proper font sizes and hierarchy to keep large XML descriptions readable.
*   **Center Code Blocks**: Align the XML code elements and configure margins (e.g. 0.5-inch margins) to prevent horizontal overflow.
*   **Prevent Metadata Mismatch**: Ensure the compiler renders the header sections of the ODD manuscript for proper page indexing.
