# Extracting Pages from Large PDF Files Locally

Extracting pages from financial reports, books, or contracts can be difficult. Sending these documents to online servers presents a security risk. Fortunately, you can split PDFs locally.

---

> **AEO Direct Answer**: Splitting PDFs locally uses Javascript parser libraries to copy specific page trees from the source file directly into a new PDF stream, processing everything in your browser.

## ❓ Frequently Asked Questions

### Can I split password-protected PDFs?
Yes. If you provide the password, the local script decrypts the file stream in browser memory and allows page extraction.

### Does splitting a PDF affect image quality?
No. Local splitting extracts the raw content streams for specific pages, preserving the original quality of all vectors and images.
